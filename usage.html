③ 사용법

10. 서버 켜고 게임에 접속하기

  1. 디스코드 채팅창에 /서버켜기 입력 → 엔터 (관리자 역할만)
    • 슬래시 명령 — 디스코드 채팅창에 / 를 치면 나오는 봇 명령 목록. 골라서 엔터
  2. 2~5분 기다리면 알림 채널에 접속 주소가 올라옵니다 (예: 접속 주소 3.35.xxx.xxx:8211)
    • ⚠️ 서버를 켤 때마다 주소(IP)가 바뀝니다. 매번 새 주소로 접속하세요 (고정 주소는 꺼져 있을 때도 요금이 나와서 쓰지 않습니다)
  3. 접속 비밀번호는 관리자가 /비밀번호 보기 로 확인해 친구들에게 알려 줍니다 (13절)

팰월드에서 주소로 직접 접속하기

  1. 팰월드 실행 → 첫 화면에서 멀티플레이 참가 (Join Multiplayer Game) 판매자 확인 필요: 메뉴 이름은 공식 문서에 없음 → 리허설 화면으로 확정
  2. 서버 목록 화면 아래의 주소 입력칸에 알림 채널의 주소를 그대로 입력 — IP:포트 형식 (예: 3.35.xxx.xxx:8211)
  3. 접속 버튼 → 비밀번호를 물으면 입력 판매자 확인 필요: 버튼 이름·비밀번호 창은 공식 문서에 없음 → 리허설 화면으로 확정
  • 메뉴 이름은 게임 버전·언어에 따라 조금 다를 수 있습니다 (판매자 확인 필요 — 리허설 화면으로 확정 예정)
  • 커뮤니티 서버 목록에서 찾는 방식이 아니라, 주소를 직접 입력하는 방식입니다

11. 서버 켜기·끄기·상태 — 자주 쓰는 명령

명령누가하는 일
/상태누구나켜짐 여부, 접속자 수, 켜진 지 얼마나 됐는지, 자동 종료까지 남은 시간
/서버켜기관리자 역할서버 켜기 (보통 2~5분)
/서버끄기관리자 역할저장·백업 후 끄기. 접속자가 있으면 멈추고 알려 줌 (강제 를 고르면 접속자가 있어도 끔)

저절로 꺼지는 규칙 (요금 아끼기)

  • 접속자가 0명인 상태가 30분 이어지면 저장·백업 후 자동으로 꺼집니다
  • 단, 켠 뒤 최소 20분은 켜 둡니다 (친구들이 들어올 시간)
  • 예: 아무도 안 들어옴 → 약 30분 뒤 꺼짐 / 놀다가 모두 나감 → 마지막 사람이 나가고 약 30분 뒤 꺼짐
  • 꺼지면 알림 채널에 "접속자가 없어 서버를 자동 종료했습니다 (마지막 접속 종료: HH:MM)" 가 올라옵니다

매일 새벽 5시 재시작

  • 팰월드는 오래 켜 두면 메모리를 점점 많이 써서, 서버가 켜져 있으면 매일 05:00 에 게임만 재시작합니다 (5분 전에 게임 안에 공지, 1~3분 뒤 다시 접속 가능)
  • 꺼져 있으면 아무 일도 하지 않습니다

백업

  • 켜져 있는 동안 3시간마다, 그리고 꺼질 때마다 월드를 자동 백업합니다 (최근 30개 보관)
  • 월드를 예전으로 되돌리고 싶으면 판매자에게 문의하세요 (디스코드 명령으로는 하지 않습니다)

12. 게임 설정 바꾸기 — /설정

명령누가하는 일
/설정 보기누구나바꿀 수 있는 설정과 지금 값
/설정 변경 항목:<고르기> 값:<입력>관리자 역할설정 1개 바꾸기
/설정 프리셋 이름:<고르기>관리자 역할여러 설정을 한 번에
/설정복구관리자 역할바로 전에 바꾸기 전으로 되돌리기 (월드는 그대로)

바꿀 수 있는 설정 8개

항목범위기본
경험치 배율0.1 ~ 101
포획 확률 배율0.1 ~ 101

프리셋

이름내용
기본모든 배율 1배, 사망 시 아이템만 잃음
느긋하게경험치·채집 2배, 포획·드롭 1.5배, 밤이 빨리 지나감
빠르게경험치·채집 3배, 포획·드롭 2배, 사망해도 잃는 것 없음
어렵게경험치 0.5배, 포획·채집·드롭 0.8배, 사망 시 모두 잃음, 노후화 게임 기본

알아 둘 것

  • 바꾸기 전에 자동으로 백업합니다
  • 언제 적용되나요: 접속자가 0명이면 게임만 바로 재시작해 적용 / 누가 접속 중이면 다음 재시작 때 (다음에 켤 때, 또는 새벽 5시) — 접속 중인 친구가 튕기지 않게 하려는 것
  • /설정 보기 에 2 → 3 처럼 화살표가 있으면 "다음 재시작 때 적용 예정" 이라는 뜻
  • 서버가 꺼져 있으면 "먼저 /서버켜기" 라고 나옵니다
  • 위험한 값(사망 페널티 All, 노후화 0)은 확인 버튼이 한 번 더 나옵니다
    • 노후화 0 = 건물이 닳지 않지만, 버려진 건물이 정리되지 않아 오래 쓰면 서버가 느려질 수 있습니다
  • 바꾼 내용은 알림 채널에 ⚙️ 로 모두에게 공지됩니다
  • 이 8개 말고 다른 설정이 필요하면 판매자에게 문의하세요

13. 접속 비밀번호 — /비밀번호

명령누가하는 일
/비밀번호 보기관리자 역할지금 비밀번호와 적용 여부 (✅ 적용)
/비밀번호 변경관리자 역할무작위로 바꾸기, 또는 입력창에 직접 입력 (영문·숫자 4~32자)
  • 이 명령의 답은 명령한 사람에게만 보입니다 ("나만 보기"). 친구에게는 개인 메시지 등으로 따로 알려 주세요
  • 바꾼 비밀번호도 설정처럼 0명이면 바로, 접속 중이면 다음 재시작 때 적용됩니다
  • 비밀번호를 아예 없애는 기능은 없습니다 (아무나 들어오지 못하게)
  • 알림 채널에는 "바뀌었습니다"·"적용됐습니다" 만 올라오고 비밀번호 자체는 올라오지 않습니다

⚠️ 화면을 캡처해 올릴 때: /비밀번호 화면은 비밀번호가 적힌 줄과, 그 아래 "답장" 미리보기 줄(위 메시지 내용이 짧게 다시 보이는 줄)을 둘 다 가려 주세요. 미리보기에도 비밀번호가 보일 수 있습니다.

실수로 보였다면 /비밀번호 변경 으로 바로 바꾸세요.

15. 자주 묻는 질문

Q. 관리자인데 명령에 🔒 가 뜨고 거부돼요

→ 내 디스코드 계정에 4절의 관리자 역할이 있는지 확인하세요 (내 이름 우클릭 → 역할). 역할을 새로 만들었거나 다른 역할로 바꾸고 싶으면 판매자에게 문의하세요.

Q. 알림 채널 메시지 보낸 사람 이름이 "Captain Hook" 이에요

→ 웹후크 기본 이름입니다. 채널 편집 → 연동 → 웹후크 → 그 웹후크를 눌러 이름·아이콘을 바꾸고 저장하세요. 주소는 그대로라 다시 설치할 필요 없습니다.

Q. 방금 껐는데 /상태 가 "🟡 서버가 막 켜져 아직 준비 중" 이라고 해요

→ 켠 지 몇 분 안에 끄면 이렇게 잘못 나올 때가 있습니다 (알려진 문제, 고칠 예정). 1~3분 뒤 다시 /상태 를 하면 맞게 나옵니다.

Q. 접속이 안 돼요

→ ① 알림 채널의 가장 최근 주소로 접속했는지 (켤 때마다 바뀜) ② /상태 가 "🟢 실행 중" 인지 ③ 관리자에게 /비밀번호 보기 가 "✅ 적용" 인지 확인. 그래도 안 되면 판매자에게.

Q. /서버켜기 했는데 "이미 켜지는 중입니다" 가 나와요

→ 이미 켜지고 있는 중입니다. 2~5분 기다려 알림 채널의 접속 주소를 보세요.

Q. 놀고 있는데 서버가 꺼졌어요

→ 접속자 0명 30분이 아니라면 문제일 수 있습니다. 알림 채널의 메시지를 캡처해 판매자에게 보내 주세요. 마지막 백업이 남아 있습니다.

Q. 요금 알림 이메일이 왔어요

→ /상태 로 서버가 켜져 있는지 보세요. 오래 켜져 있었다면 /서버끄기. 이상한 요금이면 판매자에게.

Q. 슬래시 명령이 안 보여요

→ 디스코드 앱을 껐다 켜 보세요. 그래도 안 보이면 판매자에게 (명령 등록을 다시 해야 할 수 있음).
